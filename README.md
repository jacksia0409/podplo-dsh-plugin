# PodPlo Plugin v0.1.35

本版集中发布四项此前只在源码中的功能：图转文会把成功文字保存为 TXT 并进入处理记录；「我的 DNA」以原图封面和可编辑简介保存反推结果，并可从详情或公共生图框「＋」选择；生图提交后自动清空并跳转处理记录，在任务台账查看进度或停止剩余；轮廓测长会在文件包含可靠物理分辨率时按主体自动填写尺寸，没有尺寸信息则保持空白。

图转文与 DNA 反推均只展示并原样确认服务端报价，支持 0.01 等小数积分，不在客户端硬编码售价。DNA 的隐藏规则 A/B 不进入普通用户端；管理员仍需在后台配置并启用反推 Skill A，价格就绪不等于反推规则已就绪。

本版源码回归、类型检查和相关隐藏界面检查均使用隔离夹具完成，所有原生窗口 shown/focused=0；未使用真实账号、未产生真实收费请求，也未安装或重启日常 DSH。

## 0.1.34：生图框 Skill 分类浏览

本版把生图框的 Skill 选择改为分类浏览对话框：Skill 库、我的收藏、我创建的三个页签，卡片显示封面；收藏支持文件夹与备注，个人 Skill 支持服务端搜索与游标分页，Skill 族进入成员列表后选择。选中后仍按原接口核对版本与生图绑定，未改服务协议、MCP 定义、批量任务或主站。

本版源码回归、类型检查及隐藏界面检查通过；按用户当前授权只执行打包与公开发布，未安装或重启日常 DSH。

## 0.1.29基础功能：大图测长、TXT 报告与处理记录／我的收藏

- 轮廓测长支持最高 1 亿像素的常规高分辨率图片，不要求先缩图或裁掉透明边；透明底与白底仍按原始分辨率识别全部独立外轮廓，内部孔洞不计。超出受控资源上限时会明确提示，不修改原图。
- 测长可批量导入并仅显示本次上传，逐张保留各自的实际宽高；测量完成后可导出带 UTF-8 BOM 的 TXT 报告，记录文件名、尺寸、近似长度、轮廓数量和阈值。普通测量保持只读，主动导出的报告进入处理记录。
- 「历史记录」更名为「处理记录」，「我的素材」更名为「我的收藏」；个人「我的 Skill」移入我的收藏，可新建、编辑、删除和选入生图框。编辑原条目不会误存为新副本，只有明确选择「另存副本」才创建新条目。
- 描边参数界面只保留像素输入；手动工具箱新页面的裁边透明度阈值默认改为 22，仍可手动调回 0。已有预设、旧任务和 AI 单工具继续沿用原值语义。
- 保留 0.1.28 的单面镜像、不透明图片明确提示，以及原有授权、账号隔离、文件保护和幂等恢复。本版无后端或数据库变更。

## 0.1.28：单面镜像、描边像素输入与明确错误提示

- 输出设置的拼接方向旁新增「单面镜像」：左右为左原图＋右空白镜像，上下为上空白镜像＋下原图；空白侧保留白底外形与细轮廓。不选择拼接时自动取消并禁用，预览、保存和预设一致。
- 描边的间距、线宽、平滑支持直接输入像素数值，与百分比及滑块联动。按当前主体长边换算，批量与预设仍沿用百分比；无有效主体或前序预览尚未更新时不能使用旧基准。
- 描边遇到不透明图片时，明确指出原文件名并提示先抠图、保存为透明 PNG；批量失败不会发布半批成果。
- 保留0.1.27的默认直接AI、单项确认兼容、全工具批量导入、轮廓测长、素材裁剪、统一历史、父工具授权和幂等恢复。本版无后端或数据库变更。

## 0.1.27：直接AI、单次生成修复与工具箱批量导入

- 未指定 Skill 或工具时，可直接 AI 生图／改图，无需补选 Skill；明确指定时保留原选择。支持文字生图、已有图片改图及已登记的多阶段串联，用户原文、模型／Eco和一次整单确认保持。
- 单次普通生图兼容旧服务的本人界面入口；明确参数拒绝显示“确认未完成，未提交生图”，可重新核验；网络未知或可能已预留时保持待核对与防重复提交。
- 工具箱全部图片工具支持批量导入和逐图预览。普通处理／轮廓测长最多100张，图片分割最多10张；单张50MB、单次导入250MB。测长按图片保存独立实际宽高；分割、素材裁剪继续按所选图片批量保存。移除当前列表图片不删除源文件或历史。
- 保留轮廓测长、来源递归抽样、统一历史归档、原Skill与工具授权、个人积分钱包、用户文件保护和恢复。直接AI整单要求配套后端能力；旧服务不会被用来绕过确认或改为其他生图服务。

## 0.1.26：轮廓测长、递归抽样与历史归档修复

- 工具箱「图片处理与描边」新增「轮廓测长」：输入实物宽高后，可在原图上预览外轮廓并显示全部外轮廓的近似总长度。首版仅支持透明背景或接近纯白背景的图片；内部孔洞不计，多个不相连主体分别计算，结果会提示外轮廓数量。
- 测长按前景实际包围框分别换算横向和纵向比例，不要求图片等比缩放。轮廓来自像素边界并经过轻度简化，因此属于近似值；压缩碎点可能被计作独立轮廓，应核对预览并按图片调整背景容差，容差并非越高越好。低分辨率、空白、背景不受支持或轮廓过于复杂时会明确拒绝或提示，不修改原图，也不保存为历史成果。
- 多来源任务的授权目录新增受限递归清点与抽样，可跨子目录选择图片；默认最大深度为 8，且不跟随符号链接或隐藏目录。大素材库先清点和筛选再读取最终样本，超过深度、图片数或目录数上限会明确阻断，不会静默截断。
- `podplo_inspect_task` 可只读查看来源数量、目录结构与精确诊断；该检查不上传、不计价、不执行，也不冻结后续正式任务的随机结果。
- 已成功保存的 Skill 与本地工具图片会统一进入历史记录；旧保存目录已被移除时，新归档改用受控默认目录，同时保留旧设置和已有档案位置。升级后可自动接入此前已完成但尚未进入历史的本地成果，不重新生成或重复加工。
- 「图片分割」的白底素材裁剪模式与参数区样式已补齐，保留原平均切分及原有授权边界。
- 本版继续沿用个人积分钱包、一级工具授权、账号隔离、整单确认、幂等恢复与历史文件保护；不包含团队钱包或新的主站自动授权。

## 0.1.25：多来源任务与素材裁剪

- 工具箱“图片分割”新增白底组图素材裁剪，将识别的素材分别输出为透明 PNG；保留平均切分、原图、父工具授权和历史记录。
- 保留现有固定／随机 Skill、模型与 Eco 参数、用户额外规则原文、各阶段成果、个人积分钱包及账号隔离。
- 此前源码验证使用隔离账号／合成素材；本轮未进行安装包运行、新装或升级验收。真实模型自然语言规划、真实账号完整流程及 Windows 实机尚未验收。

## 0.1.24：图片分组与确认前参数纠错

- 图片分组、Skill 分配与后续加工独立组合；支持顺序、随机、全部共同输入和明确组合，每组多张图一起生成一张结果。
- 支持两两、三三、四四组合；Eco 的参考图总数上限按模型核验，个人 Skill 自带参考图也计入，超限不删图、不自动关闭 Eco。
- 后续 AI 与工具／预设使用每组真实阶段输出；整单一次确认，重复调用、恢复和拒绝后不重复执行。
- 确认前明确可修正的参数错误可以在保留完整要求时修正；权限、报价确认及开始执行后的保护保持。
- 不恢复文本模型融合，不包含团队钱包功能。以下为保留的既有能力。

## 0.1.23：AI Skill 与本地工具平级

- AI Skill 生图／改图与本地工具／JSON 预设是平级任务入口；纯本地加工无需选择 Skill，也不调用生图模型或进入 AI 积分确认。
- 支持按规划串联、分支和选取阶段结果；后继阶段接收实际输出，不回退原图或漏掉已声明阶段。
- 各阶段成果统一进入历史记录，任务根目录按任务规划命名，并保留原图、失败、未执行与停止状态。
- 保留 0.1.22 的确定性原文提示词、参数、工具权限、整单确认／预留、账号隔离、幂等、恢复和历史保护；不包含团队账号功能。

## 保留的既有能力

本版保留并展示各阶段实际成果，明确标注失败与未执行；任务总结只列结果。

- 各个已登记生成和本地加工阶段的成功成果均保留，包括后续阶段使用的图片。
- 前序失败导致后继未执行时分别标明；部分成功不会显示为整单成功。
- 任务总结只列成功、失败、未执行数量和必要位置，不复述过程。
- 保留现有文件保护、恢复与防重复执行机制；积分由插件计算，确认整单后才能执行。

当前配套生产后端使用个人积分钱包；团队钱包尚未上线。继续使用确定性原文提示词，不恢复文本模型融合。

- Agent 只需声明素材范围、Skill 选择、阶段关系和用户明确给出的参数；Host 负责固定随机结果、展开依赖、生成本地加工计划并计算整单积分。
- 插件使用公开最终整数售价表一次计算完整订单。确认卡展示各阶段、模型、AI 张数、阶段积分、本地加工、预计成品、整单积分和当前钱包余额。
- 用户确认前不会预留积分或创建生图任务；确认后主站再次核对价格版本、不可变方案摘要、金额和消费主体，再原子预留整单额度。
- 文件夹、当前会话图片和已有云素材都可作为多阶段根来源，也可在同一整单混合使用。后继阶段由 Host 自动接收已验证的前序输出，不逐阶段重新调用聊天模型。
- 订单与逐项请求使用持久化幂等标识；提交回包丢失时先查询原订单，避免重复收费。停止、过期、撤权或依赖失败只释放尚未消费的额度，独立分支可继续。
- 默认 Agent 不再读取旧的庞大批量参数结构；旧低层入口仍保留给既有界面和兼容流程。

整单快速入口要求主站同时支持整单预留协议，并返回与插件一致的公开价格版本。旧主站会在生成确认卡和收费前明确停止，不会静默改走逐图报价。生图模型的 `background`、`output_format` 等能力仍以主站当前模型 schema 为准。

本版继续保留 0.1.17 的多阶段恢复、一级工具授权、公开工具清单、统一收藏、本地历史记录和 Skill 分类修复。

## 保留的工具授权与收藏功能

- 「图片处理与描边」统一使用固定一级 ID `image-processing-outline`，旋转翻转、调色、描边、裁剪透明图杂边、尺寸、出血、输出设置和轮廓测长继承同一有限期限授权。
- 「图片分割」继续使用 `grid-split`。缺少、过期或撤销授权时，插件在界面、预设、AI／Skill、延迟步骤和最终保存前均拒绝对应执行。
- 插件包及公开仓库根目录携带带版本与摘要的 `tool-registry.json`，供 Web 管理员手动检查和同步目录。同步目录不自动新增、延长或删除用户授权。

继续包含 0.1.15 的功能：

- Skill 族内的每个成员可独立收藏，不再从族卡片收藏整个族；已有族收藏继续可用。
- 图库图片与 Skill 可以放进同一个本机收藏文件夹，共用未分类、备注、封面、数量、搜索和移动操作。
- 我的素材移除“收藏／上传”胶囊、素材上传页面及“全部收藏”入口，通过文件夹浏览收藏。生图、个人 Skill、工具箱与图片分割的选图入口保留。
- “处理结果”更名“历史记录”，统一展示这台电脑仍存在的已下载成品图片，支持预览、时间与项目筛选及打开任务文件夹；不提供定位单张文件或选入会话入口。
- 本地成品或文件夹删除后，重新进入、回到前台或刷新时不再展示；不会自动补回删除的图片。
- 移除历史记录下的“工具记录”区块及云端历史混排。
- Skill 分类使用实际分类 ID 筛选，“全部分类”恢复显示全部。

收藏文件夹及备注按账号保存在当前电脑，不上传主站、不跨设备同步；原有云端收藏机制、官方 Skill 名称与内容保持。删除文件夹保留收藏及备注，成员回到未分类。

升级不会把原七个模块授权自动扩大为「图片处理与描边」父授权；父授权需由管理员显式设置。已有「图片分割」授权、授权期限和历史记录保持。积分批准、账号隔离、各阶段成果与简短任务总结、错误恢复及历史文件保护保持。

## 安装与升级

需要先安装 DeepSeek Harness。这是 DSH 插件，不是独立 App。

可在官方插件管理器添加仓库地址：
https://github.com/jacksia0409/podplo-dsh-plugin

已安装用户可使用本版标签地址升级：
https://github.com/jacksia0409/podplo-dsh-plugin#dsh-plugin-v0.1.35

也可通过官方插件管理器选择本地 TGZ。生成或加工任务运行时不要更新；管理器支持热安装时无需重启。不修改 DSH 核心、账号或模型配置。

插件默认尝试所有 DSH 版本（含预发布版），不代表所有版本已验收；宿主接口变化时仍需适配。Windows 使用通用 TGZ，尚未完成 Windows 实机验收。


本版取消 Skill 生图文本模型融合：客户端仅传用户额外规则原文，无则留空，服务端按固定格式组装。保留 0.1.20 全阶段成果、失败/未执行标注、简短总结、整单确认、权限与幂等保护。
