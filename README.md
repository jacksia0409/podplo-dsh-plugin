# PodPlo Plugin v0.1.7

需要 DeepSeek Harness 0.2.2-rc.1。这是 DSH 插件，需先安装 DSH；不包含独立 App。

## 本版内容（2026-11-10）

- 新任务目录为 `日期_时-分_图片加工/成品/`，只交付最终成品与任务总结。
- 有意义的原名保留，数字／ID 来源名使用 `图片01_成品`，加工阶段不反复叠加到文件名。
- 不导出原图副本、中间图、校样或校验图；恢复所需数据由内部缓存管理。
- 连续加工成功后才替换对应成品；失败保留已有结果，用户改动过的文件不覆盖。显式镜像等最终分支继续保留且命名稳定。
- 历史文件不迁移、不改名、不清理。纯生图且无后续加工时，生成图本身就是成品。
- 保留此前的 instructions 可选、路径确认、原生积分审批、成果目录打开和工具箱预设导入功能。

## 安装与升级

通过 DSH 官方插件管理器选择本地 TGZ 安装。生成或加工任务运行时不要更新；管理器支持热安装时无需重启。不修改 DSH 核心、账号或模型配置。

这是本地安装候选；打包安装不代表已公开发布到 GitHub。Windows 使用通用 TGZ，尚未完成 Windows 实机验收。
