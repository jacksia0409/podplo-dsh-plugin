# PodPlo Plugin 0.1.51

本版承接正式 0.1.49，并修复参考图操作菜单、已上传图移除入口与局部重绘窗口在窄视口中的可用性。

- 四方连续修缝保留横／竖／方图原比例，预览不显示十字蒙版，范围仅小／中／大，默认中。
- 工具箱支持批量导入、追加到队尾及选择；提交后进入处理记录，按来源顺序逐张产出，同批只有一条记录。
- 测长逐图保留尺寸及有效测量设置，分别生成TXT；分割逐张输入产出切片。
- 修缝按钮直接显示本地总积分；一次点击自动完成服务端验价和提交，不再展示独立核价或二次确认。金额变化、准备过期或响应不完整时停止，未知提交沿原任务核对，不自动付费重提。
- 模型菜单固定按 `image v2.5`、`K2 文生图`、`image v2.5 luna`、`Doubao Seed 2.0 Mini` 排列。
- 四项仍使用稳定内部标识 `gpt-image-2-5-flare`、`krea-2-turbo`、`gpt-6-luna`、`doubao-seed-2.0-mini`；`image v2.5 luna` 仅为 GPT-6 Luna 的展示名，不改变任务模型。
- Flare／Krea 缺少目录能力、账号未开通或能力信息不完整时仍显示但禁用，不伪造供应商 UUID，也不会进入上传、核价或收费提交。
- 参考图、本人结果图和放大预览可进入局部重绘；直接涂抹生成区域图，不提供独立蒙版上传入口。
- 参考图「⋯」菜单使用顶层浮层，按可用空间向上或向下展开，不再被缩略图裁切。
- 已上传参考图提供右上角 ×，只移除当前草稿引用并使旧报价失效，不删除云端原图或已接纳任务。
- 局部重绘窗口独立挂载到页面根层；标题和底部操作保持可见，中间编辑内容在窄屏中滚动。
- 我的 DNA 使用正方形封面和悬停／键盘「使用」入口；结果详情使用紧凑布局并显示已核验的生图参考图。
- 浮动生图框展开动画期间的菜单位置持续跟随，关闭和卸载时清理监听。
- 重新打开工具页不自动重做。账号切换、文件外改／删除及未知提交继续受保护。

通过 DSH 官方插件管理器填写本仓库地址安装，或使用 Release 中的 TGZ。安装不会自动重启宿主。
局部重绘、K2 和四方连续图修复的真实请求仍依赖配套服务能力；服务未开放时会明确阻断，不自动改走其他收费路径。
