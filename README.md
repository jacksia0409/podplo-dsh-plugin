# PodPlo Plugin v0.1.38

适用于 DeepSeek Harness 的 PodPlo 插件，提供 Skill 库、我的收藏、AI 生图与本地图像工具。

## 本版更新

- 单次、批量、图转文、DNA 提取和工具保存确认后立即进入处理记录，统一查看 loading、进度、完成、失败与待核对状态。
- 结果筛选支持全部类型、工具处理和 AI处理，可与搜索及时间范围组合使用。
- 我的 DNA、我的 Skill 统一为桌面四列小卡片，窄窗口自动调整列数。DNA 任务核对入口集中到处理记录，配方保持私有。
- 图转文与 DNA 新任务可选择 GPT-6 Luna、Doubao Seed 2.0 Mini，默认 Luna；Haiku 不再用于新调用，已接纳旧任务仍可核对。
- 底部模型、参数和「+」菜单向上展开，选择、Esc、外侧关闭后不残留、不穿透点击。

## 安装和更新

先安装 DeepSeek Harness，在插件管理器中填写：

```text
https://github.com/jacksia0409/podplo-dsh-plugin#dsh-plugin-v0.1.38
```

也可下载本页 TGZ 或 macOS ZIP。ZIP 包含安装器和同一 TGZ。安装到日常 desktop profile 前请完全退出 DSH，安装后按宿主提示加载。插件默认尝试所有 DSH 版本，实际兼容性取决于宿主接口；这不代表每个平台和宿主版本均已验收。

## 使用说明

- 在 Skill 库、我的收藏或生图框选择 Skill；DNA 可从我的 DNA 选择并与新参考图配合使用。反推 DNA 需要管理员在后台配置并启用对应规则，未就绪时会明确提示。
- AI 任务先显示服务端积分报价，再由用户确认。普通图转文、DNA 反推支持服务端 0.01 等小数积分报价，实际售价以当前报价为准。
- 处理记录显示提交与处理状态，以及已保存的图片和 TXT。批量支持「停止剩余」；未知付费任务只核对原请求，不自动重复收费执行。
- 工具箱包含图片处理与描边、图片分割和轮廓测长；测长支持透明／白底图、最高1亿像素、可靠尺寸自动读取及手动尺寸。保存或导出后统一进入处理记录。
- 我的 DNA 仅展示封面及可编辑简介，不提供配方正文、复制或 TXT 导出。普通图转文可保存并复制识别文字。
- 原图保留；本地文件被移动、外改或删除后，普通刷新不会覆盖或自动重建。登录账号、授权及本地任务按原边界隔离。

本版使用隔离夹具完成源码、后台界面与安装验证；未以测试替代真实收费全量验收。日常 DSH 不会因公开发行自动安装或重启。
