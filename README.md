# PodPlo Plugin

需要 DeepSeek Harness 0.2.2-rc.1。这是插件，需要先安装 DSH。

## 本版更新

页面顶部显示 **PodPlo v0.1.3**。

选择固定边后，直接在“固定高”或“固定宽”输入框填写目标值，跟随边为只读自动计算。导出会校验全部模块（包括未勾选模块）的参数；空值、越界值等无效参数会阻止下载并指出对应模块，避免静默写成 0、null 或旧值。勾选状态、旋转翻转、调色、描边、裁边阈值、尺寸、出血及输出参数均保留；图案填充的图片不嵌入 JSON，预设会明确标记需另选图案。

尺寸区可明确选择“固定高，宽跟随”或“固定宽，高跟随”。导出预设只记录固定边及数值，另一边按每张图经过描边、裁边后的比例计算；换图保留已设定目标。取消比例锁定后保存固定宽高。预设 schemaVersion 为 2，使用 sizing=height／width／fixed，不把当前图算出的跟随边写成固定目标。

保留裁边透明度阈值，范围 0～254，默认 0。Alpha 小于或等于阈值的像素不参与裁切边界计算；只裁成一个矩形，矩形内部像素原样保留。调整后即时预览，预设包含该参数；数值越大，越可能裁掉淡色内容。阈值过高、没有有效主体时不裁剪，保留原图并提示复核。旧任务未指定阈值时仍按 0 执行。

DSH 插件列表名称 PodPlo Plugin、内部包标识 @podplo/dsh-plugin 保留，更新比较使用完整版本。

保留 alpha.77 的处理结果功能：列表／卡片切换和时间筛选（今天、近 7 天、近 30 天、自定义日期），可组合项目和搜索；每次独立工具箱保存一个批次，同一次保存重试不会重复建批，已有批次保持原样。

卡片、列表和详情支持“删除批次”。确认后永久删除该批次记录及整个本地任务文件夹，包括成果、参考副本、任务总结和自行放入的其他文件；云端素材、源素材和其他批次保留。正在生成、保存或加工的批次不可删除。删除后刷新或重启不会重建该批次。

工具箱继续只保存最终成品图或选择的 PDF，不额外保存校样图和印前 JSON。校样仍可预览，原图与待复核规则保留。

保留“输出设置”中的左右／上下镜像拼接：左右为左原图＋右水平镜像，上下为上原图＋下垂直镜像，分别宽度或高度翻倍，DPI 保留。每张输入独立处理，预览和保存使用拼接后的成品；额外镜像默认关闭，可按需另存最终成品的水平镜像。

工具箱无需先创建聊天，按旋转翻转、调色、描边、裁剪透明图杂边、尺寸、出血、输出设置的顺序处理。支持尺寸比例锁、毫米出血、透明留边和 PNG／JPEG／WebP／PDF。PNG／WebP 支持透明，JPEG 按透明区底色合成。既有登录、账号隔离、任务成果、生成报价和审批规则保留。

## 安装与升级

新用户在 DSH「插件 → 添加插件」输入：

```text
https://github.com/jacksia0409/podplo-dsh-plugin
```

已有用户可在相同入口使用本版完整标签地址升级：

```text
https://github.com/jacksia0409/podplo-dsh-plugin#dsh-plugin-v0.1.3
```

同一 GitHub 地址重复安装可能触发 DSH 的 ambiguous-install，已有用户请使用带版本标签的升级地址。任务运行时不更新，不自动降级，不强制重启。此前收到的页面检查／更新按钮不可用反馈仍待排查，本版请使用上述完整标签地址升级。

[本版 Release](https://github.com/jacksia0409/podplo-dsh-plugin/releases/tag/dsh-plugin-v0.1.3) 提供 macOS ZIP 和通用 TGZ。macOS ZIP 内含安装命令；通过 CLI 安装前请正常退出 DSH，正在使用时可通过官方插件管理器导入 TGZ。Windows 尚未实机验收。
