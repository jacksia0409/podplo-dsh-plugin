# PodPlo Plugin v0.1.6

需要 DeepSeek Harness 0.2.2-rc.1。这是 DSH 插件，需先安装 DSH；不包含独立 App。

## 本版更新（2026-11-10）

- 指定 Skill 时，额外 instructions 可以不填或留空；宿主按 Skill 执行，Agent 不补写创作要求。
- 用户提供“桌面＋预设文件名”或在原生提问中选择确认完整路径后，无需反复确认同一路径。
- 原生审批不可用、关闭或状态读取失败，不再主动停止整个任务。报价保留，不自动扣费或提交；可在 PodPlo 报价卡确认。用户明确拒绝仍取消该报价。
- 打开任务文件夹只要求已登记的当前账号目录仍存在；图片移动、修改或删除不阻止打开文件夹。
- 新成果以“原始名＋处理方式”命名，重名追加序号；已有成果不改名。
- 图像工具箱“导出预设”旁增加“导入预设”，恢复勾选、全部参数、固定边、四边出血和镜像拼接设置；非法文件不改变当前设置，图案图片需要重新选择。

文件夹整批可使用个人 Skill 和多组不同预设，整批报价一次；批准后宿主自动完成生成、下载和预设加工。Agent 仅在报价前澄清不明项，确认后报告执行状态，不评价图片质量或自行付费重做。

成果保留 AI 原图、最终加工／拼接图或所选 PDF、任务总结，不新增校样、待复核图或成果 JSON。总结记录张数、实际提交提示词及模型／Skill／工具调用。内部账号、幂等和恢复状态、用户主动导出的预设 JSON 保留。

## 安装与升级

新用户在 DSH「插件 → 添加插件」输入：

```text
https://github.com/jacksia0409/podplo-dsh-plugin
```

已有用户使用完整标签地址升级，避免 DSH 对同一安装 spec 的 ambiguous-install：

```text
https://github.com/jacksia0409/podplo-dsh-plugin#dsh-plugin-v0.1.6
```

也可下载 Release 附件中的通用 TGZ，通过官方插件管理器安装。macOS ZIP 内含同一 TGZ；Windows 使用通用 TGZ，尚未完成 Windows 实机验收。页面顶部显示 PodPlo v0.1.6。

生成中不要更新插件。使用官方管理器可热安装时无需重启；不修改 DSH 核心、其他插件、账号或模型配置。
