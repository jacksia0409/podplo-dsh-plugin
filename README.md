# PodPlo Plugin v0.1.13

本版接入主站 desktop context v2 的八个大标题工具组授权及逐项有效期校验。缺少授权、授权过期、工具 token 或组归属不匹配时均拒绝新操作；手动工具箱、预设、图片分割、AI 单工具和自动后处理会在延迟执行及发布前重新校验。

本版在插件内提供收藏文件夹与 Skill 个人备注：支持文件夹新建、改名、删除，Skill 设置备注、移动及移除收藏；DSH 可按备注和文件夹定位。原 Skill 名称、ID 和内容保持不变。文件夹和备注按账号保存在当前电脑的插件数据中，不上传主站，也不跨设备同步；原有云端收藏机制保持。删除文件夹保留收藏及备注，成员回到未分类。

需要先安装 DeepSeek Harness。这是 DSH 插件，不包含独立 App。

插件默认尝试加载所有 DSH 版本（含预发布版），不再限定为 0.2.2-rc.1；安装器也不按 DSH 版本拒绝安装。这是放宽加载条件，不代表已经验证所有版本；宿主接口变化时仍需适配。具体实测版本与范围以验收记录为准。

## 本版内容（2026-11-15）

- 八个工具大标题按各自授权有效期放行；组合计划按实际步骤逐项校验，已完成结果和幂等收据仍可读取。
- DSH 按用户意图编排 PodPlo Skill 与内置工具；图片 AI 统一调用 Skill，明确即执行，不自行改词、评图或追加处理。
- 批量模型、比例、质量、Eco 与背景参数可省略，Host 沿用现有初始化默认；显式值优先，真正缺项集中提示。保留一次整批积分批准、账号隔离及最终成品交付。
- 显式计划模式只列简短的 Skill／工具调用顺序；默认不要求工程方案。已通过规则／宿主流程及隔离原生包验证，未做真实收费模型对话验收。

## 上版内容（0.1.10，2026-11-15）

- 解除 DSH 精确版本门槛及安装器 rc.1 限制，默认尝试所有版本（含预发布版）；已在 DSH 0.2.2-rc.3 完成隔离原生验证。

## 上版内容（0.1.9，2026-11-10）

- 操作日志仅在本地保存，移除处理结果页的日志／诊断查看和复制入口；普通失败提示与恢复操作保留。每账号仍只保留最近 10 次脱敏操作。

以下既有功能继续保留：

- 新增工具箱内“图片分割”：1～6 行列平均切图，保留透明度和 DPI，PNG 成品进入处理结果。暂不自动识别或移除白／黑分隔带。
- 页面返回恢复列表、筛选、分页和滚动；详情立即打开并异步补齐；工具箱调参保留上次效果，新预览成功后替换。
- 缩略图按可见区域加载并限制并发；私有素材预览使用短时缓存；收藏写入确认后立即反馈，后台同步列表。
- 处理结果按当前页核验，避免反复检查全部文件；空闲列表停止定时刷新，隐藏页面暂停界面读取，宿主后台任务继续。
- 工具箱复用未变化的前序加工步骤和本地派生预览；内部记录分阶段诊断。
- 每账号统一保留最近 10 次脱敏操作日志，同一任务阶段合并，不在页面展示。
- 顶部账号栏和处理结果筛选区更紧凑，版本、更新与退出收进账号菜单。
- 保留新任务只交付最终成品和任务总结、历史文件保护、账号隔离、积分审批与恢复机制；不自动付费重做。
