# PodPlo Plugin v0.1.8

需要 DeepSeek Harness 0.2.2-rc.1。这是 DSH 插件，需先安装 DSH；不包含独立 App。

## 本版内容（2026-11-10）

- 新增工具箱内“图片分割”：1～6 行列平均切图，保留透明度和 DPI，PNG 成品进入处理结果。暂不自动识别或移除白／黑分隔带。
- 页面返回恢复列表、筛选、分页和滚动；详情立即打开并异步补齐；工具箱调参保留上次效果，新预览成功后替换。
- 缩略图按可见区域加载并限制并发；私有素材预览使用短时缓存；收藏写入确认后立即反馈，后台同步列表。
- 处理结果按当前页核验，避免反复检查全部文件；空闲列表停止定时刷新，隐藏页面暂停界面读取，宿主后台任务继续。
- 工具箱复用未变化的前序加工步骤和本地派生预览；新增分阶段诊断和脱敏复制。
- 每账号统一保留最近 10 次脱敏操作日志，同一任务阶段合并；处理结果页可显式复制。
- 顶部账号栏和处理结果筛选区更紧凑，版本、更新与退出收进账号菜单。
- 保留新任务只交付最终成品和任务总结、历史文件保护、账号隔离、积分审批与恢复机制；不自动付费重做。

## 安装与升级

可在 DSH 官方插件管理器添加仓库地址：
https://github.com/jacksia0409/podplo-dsh-plugin

已安装用户使用本版标签地址升级：
https://github.com/jacksia0409/podplo-dsh-plugin#dsh-plugin-v0.1.8

也可通过官方插件管理器选择本地 TGZ 安装。生成或加工任务运行时不要更新；管理器支持热安装时无需重启。不修改 DSH 核心、账号或模型配置。
