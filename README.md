# PodPlo Plugin v0.1.46

适用于 DeepSeek Harness 的 PodPlo 插件，提供 Skill 库、我的收藏、AI 生图与本地图像工具。

## 本版更新

- DNA 加参考图先显示服务端报价，确认后才上传；变价时重新确认，提交后直接进入处理记录。
- 参考图只上传一次清晰安全源；开启 Eco 时参考图长边最多 256px，关闭 Eco、图转文与 DNA 提取最多 512px。各档从上传源一次等比缩放，合规小 WebP 直接复用。
- 收藏 Skill、个人 Skill 与 DNA 可独立编辑并保存下次生效的生图预设，不改变当前生图草稿。DNA 封面完整显示，处理结果可直达对应 DNA。
- 生图框右上角集中显示批量任务与保存预设；参考图可逐张用 × 移除，也可用扫把清空当前草稿。图转文支持正文回填、文件下载和批量 TXT 打包。

## 更新与兼容

- 历史“待核对”任务不再锁住更新按钮，原任务、账务收据和「核对原提交」保留，不自动重复收费或重做。
- 正在提交、运行、下载、本地加工／保存、在途核对与待确认仍保护；更新菜单显示原因，状态结束后恢复可更新。
- 更新仍经DSH官方插件管理器，不降级、不强制重启。旧0.1.38／0.1.39的灰色按钮需先用下方标签地址升级一次，安装后采用新规则。
- 保留上一版提交结果卡片、20项分页、工具／AI类型筛选，以及我的Skill／DNA四列小卡片和更多菜单。

安装／升级地址：
`https://github.com/jacksia0409/podplo-dsh-plugin#dsh-plugin-v0.1.46`

发行不会自动安装或重启日常 DSH。附件 TGZ 与 ZIP 为同一版本；真实收费与Windows实机不在本轮验收范围。

## 使用说明

- 在 Skill 库、我的收藏或生图框选择 Skill；已保存的 DNA 可配合新参考图使用。反推 DNA 需要管理员配置并启用对应规则；DNA 只显示封面和独立简介，不提供配方正文、复制或 TXT 导出。
- AI 任务先显示服务端积分报价，再由用户明确确认。普通图转文和 DNA 反推支持0.01等小数报价，实际售价以当前报价为准；新分析任务支持 GPT-6 Luna 与 Doubao Seed 2.0 Mini，历史 Haiku 原任务仍可核对。
- 处理记录包含已保存图片、TXT及未完成结果；批量可停止剩余任务，未知结果只核对原任务，不自动重复收费。
- 工具箱包含图片处理与描边、图片分割、轮廓测长。轮廓测长支持透明／白底图、最高1亿像素、可靠尺寸自动读取及手动尺寸；原图保留。
- 本地文件被外改、移动或删除后，普通刷新不会覆盖或自动重建。登录账号、授权与本地任务按原边界隔离。

## 安装

先安装 DeepSeek Harness，再在官方插件管理器填写上述带标签地址；也可使用本页 TGZ 或 macOS ZIP。ZIP包含安装器和同一TGZ，安装到日常 desktop profile 前应完全退出DSH，再按宿主提示加载。插件默认尝试所有DSH版本，实际兼容性取决于宿主接口；这不代表每个平台和宿主版本都已验收。
