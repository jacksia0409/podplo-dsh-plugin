# PodPlo Plugin v0.1.5

原生 DeepSeek Harness 插件，需要先安装 DSH 0.2.2-rc.1；不是独立 App。Windows 已有适配，尚未实机验收。

## 安装与升级

在 DSH 官方插件管理器的“添加插件”中输入仓库地址：

```text
https://github.com/jacksia0409/podplo-dsh-plugin
```

已有用户升级请使用本版完整标签地址，避免 DSH 同一 spec 重复安装的 ambiguous-install：

```text
https://github.com/jacksia0409/podplo-dsh-plugin#dsh-plugin-v0.1.5
```

也可从本版 Release 下载通用 TGZ，经官方管理器安装；macOS ZIP 含相同 TGZ、安装命令和说明。任务运行时请等待结束再更新，不强制重启。

## 本版变化

- 文件夹整批支持个人 Skill，可给多组图片分别指定 Skill 和工具箱预设，一次报价确认。
- 预设由宿主读取并按记录的顺序、固定单边比例、毫米四边出血和镜像拼接执行，确认后自动完成下载与全部加工。
- Agent 在报价前澄清不明确需求，确认后只报告执行状态，不评价成果质量、不自行改参数或重生成。
- 裁边诊断不再分流待复核或暂停后续加工；成果保留 AI 原图、最终加工／拼接图或所选 PDF，以及记录张数、提交提示词和调用的任务总结。
- 不输出出血校样、校样预览或成果 JSON 报告。用户主动导出的预设与内部恢复、账号隔离和幂等状态保留，历史文件不删除。

已通过类型检查、155 项相关回归、隐藏 UI 和同一 TGZ 的隔离原生宿主验证。真实付费生图与 Windows 实机不在本次验收范围内。

仓库只分发预编译运行文件、安装声明和说明，不上传开发源码、登录配置或凭据。根 dist 与验收 TGZ 一致；此 README 为正式发布说明，包内 README 保留本地验收阶段说明。校验与验证范围见 Release 附件。
